    How my main works:
    -------------------------
1. Trainer Selection Phase:
   - `prompt_first_pokemon()`: Shows 4 choices (1-4), gets Trainer 1's first pick
   - `prompt_second_pokemon(first_pick)`: Shows 3 remaining choices, gets Trainer 2's pick
   - `prompt_third_pokemon(first_pick, second_pick)`: Shows 2 remaining choices, gets Trainer 1's second pick
   - `get_last_pokemon(first_pick, second_pick, third_pick)`: Automatically assigns the final Pokémon to Trainer 2

2. Battle Setup:
   - `create_battle()` initializes a battle object with:
     - Creates 4 Pokémon objects with unique stats (HP, Attack, Defense)
     - Each Pokémon gets 2 moves: "Scratch" (Normal-type) + one type-specific move (like "Ember" for Charmander)
     - Assigns the chosen Pokémon to each trainer in their selected order

3. Battle Loop (`play_game()`):
   - Runs until one trainer loses both Pokémon
   - Each turn, current trainer can:
     1. Use a move (attack)
     2. Heal their active Pokémon
     3. Swap to their other Pokémon
   - Turns alternate between trainers if action was successful

The program uses a Battle class to manage the game state and Pokémon objects to store individual Pokémon data and moves which in itself is a class. ^8WONTy0e
