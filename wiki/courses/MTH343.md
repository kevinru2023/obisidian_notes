# MTH343 — Abstract Algebra

## Textbook

**Abstract Algebra: Theory and Applications** — Thomas W. Judson (2012 edition)
Source: [[raw-sources/courses/MTH343/Judson12.pdf]]

Open-source text covering groups, rings, and fields with applications to cryptography and coding theory.

---

## Course Topics (Judson Chapter Map)

### Groups
- **Ch. 1** — Preliminaries: proofs, set theory, equivalence relations, bijections
- **Ch. 2** — Integers: induction, division algorithm, GCD, Fundamental Theorem of Arithmetic
- **Ch. 3** — Groups: axioms, subgroups, modular arithmetic, symmetry groups
- **Ch. 4** — Cyclic Groups: generators, orders, method of repeated squares (fast exponentiation)
- **Ch. 5** — Permutation Groups: cycle notation, S_n, dihedral groups D_n
- **Ch. 6** — Cosets & Lagrange's Theorem: cosets, Lagrange, Fermat's little theorem, Euler's theorem
- **Ch. 9** — Isomorphisms: Cayley's theorem, direct products
- **Ch. 10** — Normal Subgroups & Factor Groups: quotient groups, simplicity of A_n
- **Ch. 11** — Homomorphisms: kernel/image, three isomorphism theorems

### Rings
- **Ch. 16** — Rings: ring axioms, integral domains, fields, ideals, ring homomorphisms
- **Ch. 17** — Polynomials: polynomial rings, irreducibility, roots
- **Ch. 18** — Integral Domains: UFDs, PIDs, Euclidean domains

### Fields
- **Ch. 20** — Vector Spaces: basis, dimension, linear independence (over general fields)
- **Ch. 21** — Fields: extension fields, algebraic elements, splitting fields

## Key Definitions (Quick Reference)

**Group** — A set G with binary operation · satisfying: closure, associativity, identity (e), inverses.
- **Abelian** if also commutative (ab = ba for all a,b).

**Subgroup** — H ≤ G if H is nonempty, closed under the operation and inverses.

**Cyclic group** — Generated by a single element: $G = \langle g \rangle = \{g^n : n \in \mathbb{Z}\}$.

**Normal subgroup** — $N \trianglelefteq G$ if $gNg^{-1} = N$ for all $g \in G$. Required to form quotient group $G/N$.

**Homomorphism** — Map $\varphi: G \to H$ with $\varphi(ab) = \varphi(a)\varphi(b)$. Kernel $= \varphi^{-1}(e_H)$.

**Ring** — Set R with addition (abelian group) and multiplication (associative, distributes over +).

**Ideal** — Subring I ⊆ R absorbing multiplication: rI ⊆ I and Ir ⊆ I for all r ∈ R.

**Field** — Commutative ring where every nonzero element has a multiplicative inverse.

## Core Theorems

| Theorem | Statement |
|---------|-----------|
| **Lagrange** | $|H|$ divides $|G|$ for any subgroup $H$ of finite group $G$ |
| **Cayley** | Every group $G$ is isomorphic to a subgroup of $S_{|G|}$ |
| **1st Isomorphism Thm** | $G/\ker(\varphi) \cong \operatorname{im}(\varphi)$ |
| **Cauchy** | If prime $p$ divides $|G|$, then $G$ has an element of order $p$ |
| **Sylow** | $G$ has a subgroup of order $p^k$ whenever $p^k$ divides $|G|$ |
| **Ftmn Finite Abelian** | Every finite abelian group $\cong \mathbb{Z}_{n_1} \times \cdots \times \mathbb{Z}_{n_k}$ (prime-power factors) |

## Recommended Study Path

1. Master proof techniques (Ch. 1) before anything else — the whole course is proof-based.
2. Groups are the core (Ch. 3–6, 9–11); rings and fields build on this intuition.
3. Ch. 7 (Cryptography) and Ch. 8 (Coding Theory) are standalone applications good for motivation.
4. Sylow theorems (Ch. 15) are the culmination of group theory — return to them after Ch. 14.
