## Core Topics

### Double Integrals
- Defined as limit of 2D Riemann sums: $\iint_R f(x,y)\,dA = \lim_{n \to \infty} \sum_i f(x_i,y_i)\,\Delta A_i$
- Fubini's theorem allows iteration over rectangular regions in either order
- Generalizes to Type I / Type II regions with variable bounds
- Switch integration order when antiderivative is unavailable in the chosen order

See: [[wiki/concepts/double-integrals]]

## Key Theorems

| Theorem | Statement |
|---|---|
| Fubini (rectangular) | $\iint_R f\,dA = \int_{x_1}^{x_2}\int_{y_1}^{y_2} f\,dy\,dx = \int_{y_1}^{y_2}\int_{x_1}^{x_2} f\,dx\,dy$ |
| Additivity | $\iint_R f\,dA = \iint_{R_1} f\,dA + \iint_{R_2} f\,dA$ when $R = R_1 \cup R_2$ |
| Average value | $\bar{f} = \frac{1}{A}\iint_R f\,dA$ |
