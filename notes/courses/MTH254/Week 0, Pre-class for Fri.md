# Vectors
---
In this course we will be focused on vectors in the 2D plane $(\mathbb{R}^2)$﻿ or in 3D space $(\mathbb{R}^3)$﻿  
  

**Non-zero vector:** a quantity with magnitude and direction, they are usually represented geometrically by an arrow where the length represents the magnitude and the orientation is the vector’s direction.

$\text{Non-zero vector: }\vec{v}$

![[e29c44d7-d0a7-4572-a39c-a45adebb004e.png]]


**Zero vector:  
a vector with zero magnitude, geometrically represented by a point.

$\text{Zero vector: }\vec{0}$

**2D:** A vector in the 2D plane can be represented by $\vec{u} = \langle{a,b}\rangle$﻿ where a and b are the x- and y-components, representing horizontal and vertical displacement (basically represents from the tail of the arrow, to the end of the arrow) (components can be neg)

  
  
**3D:** A vector in the 3D plane is represented by $\vec{v} = \langle{a,b,c}\rangle$﻿ whose x-, y-, and z- components are a, b, and c. Orientation convention of 3D planes is as follows:

- x-axis: East
- y-axis: North
- z-axis: Up

![[a1624988-bc43-4ba7-95b1-71fe6f953102.png]]

  

**Helpful Tip:** the point $(a,b)$﻿ in the xy-plane is the pos of the head of $\vec{x} = \langle{a,b}\rangle$﻿ when the tail is placed at the origin $(0,0)$﻿ . This is similar for the xyz-space, where the point $(a,b,c)$﻿ is the pos of the head of $\vec{y} = \langle{a,b,c}\rangle$﻿, when the tail is placed at the origin $(0,0,0)$﻿.

  

**Scalar Multiplication:** A vector $\vec{u}$﻿ can be multiplied by a real number $c$﻿ called a scalar. The product is denoted by $c\vec{u}$﻿, and is the result of scaling the length of $\vec{u}$﻿ by $|c|$﻿ and keeping the same direction if $c > 0$﻿ or reversing the direction if $c < 0$﻿

![[Screenshot_2024-09-26_at_4.20.29_PM.png]]


**Two vectors are**  
**parallel if they are non-zero multiples of each other**
  

**Vector Addition:** The sum of vectors $\vec{u}$﻿ and $\vec{v}$﻿ is determined component-wise by adding corresponding components (basically add up like you think you would). This can be drawn by placing the tail of one vector at the head of the other, then extending it. (legit just drawing it get added lol). Notation: $\vec{u} + \vec{v}$﻿, order does not matter.(parallelogram law)

  

**Magnitude of a vector** $\vec{v}$﻿ **is denoted by** $|\vec{v}|$﻿**. In 2D you can use the Pythagorean Theorem to show the magnitude of** $\vec{v} = \langle{a,b}\rangle$﻿ **is** $|\vec{v}| = \sqrt{a^2+b^2}$﻿**. This is the case in 3D as well with** $\vec{w} = \langle{a,b,c}\rangle$﻿ **where** $|\vec{w}| = \sqrt{a^2+b^2+c^2}$﻿**.**

  

**Unit vector:** a vector $\vec{u}$﻿ is a unit vector if it has $|\vec{u}| = 1$﻿. A unit vector is denoted by $\hat{u}$. Additionally,  $\vec{u}=\frac{1}{|\vec{v}|}\vec{v}$﻿. 

  

**Engineering notations:**

- $i = \langle 1, 0 \rangle$ or $\langle 1, 0, 0 \rangle$
- $j = \langle 0, 1 \rangle$ or $\langle 0, 1, 0 \rangle$
- $k = \langle 0, 0, 1 \rangle$

**Then by scalar multiplication and vector addition,** $\langle{a,b}\rangle = ai + bj$﻿ **and** $\langle{a,b,c}\rangle = ai + bj+ ck$﻿

  

$\boxed{\vec{v} = |\vec{v}|\cdot \hat{u}}$
