
# Definition of Linear Regression 
First to understand what and how Linear Regression is let's define what Linear Regression means. 

> [!Info] Regression
> We are predicting some continuous output y

> [!Info] Linear
> We assume there is a linear relationship between x & y

So linear regression is used for predicting some continuous output y given a function that we assume has a linear relationship between x & y, i.e. it can be modeled by a linear function.
