# A. Radio Prize: 

This problem is basically running through a graph and getting the cost it takes to traverse each node.

This is how they have input: 
1. Single int representing amount of cities 
2. $n$ space-seperated integers $t_{i}$ where ($1\leq t_{i} \leq 1000$) where $t_i$ is the tax in each city 
3. The following $n -1$ lines each have 3 ints: $u_{i},v_{i},w_{i}$. Meaning the $i\text{th}$ road connects cities $u_i$ and $v_i$ ($1 \leq u_{i}, v_{i} \leq n$), with a toll of $w_{i}(1 \leq w_{i} \leq 1000)$
